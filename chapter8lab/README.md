# Chapter 8 — Configuring Networking

RHCSA (EX200) — RHEL Networking Lab

## Skills Practised

- Inspecting network interfaces and IP addresses using `ip`
- Understanding IPv4 addresses, subnets and CIDR
- Troubleshooting connectivity with `ping`
- Inspecting and modifying routing tables
- Checking listening ports using `ss`
- Creating and removing temporary network interfaces
- Managing network connections using `nmcli`
- Understanding DHCP and static IP configuration
- Inspecting network settings using `nmtui`
- Troubleshooting DNS, gateway and SSH connectivity

## Lab Environment

- Red Hat Enterprise Linux
- VMware virtual machine
- Network interface: `ens160`

## Outcome

Completed Chapter 8 networking exercises and troubleshooting practice. Persistent static IP configuration requires further hands-on revision.
