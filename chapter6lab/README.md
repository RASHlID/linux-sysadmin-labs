# Chapter 6 – User and Group Management

Hands-on practice managing local users, groups, passwords, account ageing, and administrative privileges on RHEL.

## Skills Practised

- Understanding UID and GID
- `/etc/passwd` and `/etc/shadow`
- Root access with `su` and `sudo`
- Creating, modifying, and deleting users
- Managing passwords with `passwd`
- Password ageing and account expiry with `chage`
- User defaults and `/etc/skel`
- Creating, modifying, and deleting groups
- Primary and supplementary groups
- Managing group membership with `usermod`
- Understanding `wheel`
- Sudo configuration with `visudo`
- `/etc/sudoers` and `/etc/sudoers.d/`

## Commands Practised

- `useradd`
- `usermod`
- `userdel`
- `passwd`
- `chage`
- `groupadd`
- `groupmod`
- `groupdel`
- `id`
- `su`
- `sudo`
- `visudo`
